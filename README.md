# Buscacuartos

Buscador de subvenciones de digitalización, inteligencia artificial y ciberseguridad
para pymes de Castilla y León. Herramienta gratuita de [CLAVE 360](https://www.clave360.tech).

**Publicado en:** https://www.clave360.tech/buscacuartos/

## Cómo funciona este repositorio

`index.html` es la herramienta completa: un único archivo autónomo, sin dependencias
ni base de datos. El catálogo de convocatorias se revisa cada lunes y el archivo se
vuelve a publicar aquí automáticamente; el servidor web lo descarga de este
repositorio y lo sirve en la URL de arriba.

> No edites `index.html` a mano: la revisión semanal lo sobrescribe.

`og-buscacuartos.png` es la imagen de previsualización que se muestra al compartir el enlace.
